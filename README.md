# StayFocus — мотивационный хаб против думскроллинга

> «Твое время — твой главный ресурс.»

StayFocus — веб-приложение, которое помогает выйти из бесконечного скроллинга:
стрик побед, лимиты на ленты, честная аналитика экранного времени, планнер
реальных дел, режим спасения на 10 секунд дыхания и **тренажёр с камерой**:
когда минуты на Instagram / TikTok / YouTube заканчиваются, вернуться можно
только сделав 10 отжиманий или 20 приседаний — камера считает повторы и
проверяет технику.

**Прототип.** Стрик, графики и «сэкономленные» часы — **демонстрационные
данные**, явно помеченные плашкой «Демо-данные». Вход через Google работает
по-настоящему, если задан `NEXT_PUBLIC_GOOGLE_CLIENT_ID` (см. ниже); без него
включается честно подписанный демо-вход. Лимиты, блокировка и заработанные
минуты — настоящее состояние приложения, а расход времени по лентам
демонстрационный: веб-страница не может прочитать экранное время другого сайта.
Ничего не отправляется на сервер.

## Запуск

Требования: Node.js 20.9+ (проверено на Node 24), npm 11.

```bash
npm install
npm run dev        # http://localhost:3000
```

Проверки и продакшн-сборка:

```bash
npm run typecheck  # tsc --noEmit — без ошибок
npm run lint       # ESLint — 0 ошибок, 9 обоснованных warnings
npm run build      # next build
npm start          # продакшн-сервер после сборки
```

### Настоящий вход через Google

Скопируйте `.env.example` в `.env.local` и заполните `NEXT_PUBLIC_GOOGLE_CLIENT_ID`.

1. [Google Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials)
   → Create credentials → OAuth client ID → **Web application**.
2. Authorised JavaScript origins: `http://localhost:3000` (и прод-домен, когда он есть).
3. Client ID вставьте в `.env.local` и перезапустите `npm run dev`.

Секрет не нужен: Google Identity Services возвращает подписанный ID-токен прямо
в браузер. Приложение декодирует его payload, чтобы показать имя, почту и
аватар. Профиль хранится в `localStorage`, ничего не уходит на сервер.

Без переменной кнопка остаётся демо-входом и прямо об этом сообщает.
`NEXT_PUBLIC_SITE_URL` используется только для абсолютных OG-ссылок в метаданных.

> **Dev-нюанс Next 16:** dev-ресурсы защищены от cross-origin обращений. Если
> открываете приложение по `127.0.0.1`, добавьте его в `allowedDevOrigins` в
> [next.config.ts](next.config.ts), иначе клиентский рантайм и гидратация будут
> заблокированы. Открытие по `localhost` работает без настройки.

| `/`          | Лендинг: hero со стрик-кольцом, мотивационные карточки, «что внутри», первый шаг, 4 шага установки расширения, финальный CTA |

## Что реализовано

1. **Стрик побед.** Счётчик «дней без думскроллинга», полоса прогресса до
   следующего уровня, 6 уровней (пороги входа: 3 / 7 / 14 / 30 / 60 дней), личный
   рекорд, кнопка «Отметить день как победу» с анимацией успеха и корректным
   склонением слова «день» для EN / RU / KZ.
2. **Питомец Фокуса.** Компаньон на CSS-формах: растёт по 6 стадиям вместе со
   стриком, аура добавляет кольцо за каждую стадию.
3. **Аналитика экранного времени.** Recharts: накопительный area-график
   Instagram / TikTok / YouTube за 7 дней и сравнение «до StayFocus / эта
   неделя» с честным числом сэкономленных часов.
4. **Сэкономленное время.** Ползунок 0–6 ч переводит часы в реальные дела
   (2 ч = 10 страниц книги + разминка + урок языка + звонок близким).
5. **Планнер недели.** 7 дней × реальные задачи (спорт, учёба, чтение, свой
   проект, прогулка, семья, без Reels), 27 слотов, прогресс недели, анимация
   галочки и баннер за идеальный день. Состояние сохраняется в `localStorage`.
6. **Режим спасения.** «Хочу сорваться» → модальное окно с 10-секундным
   дыхательным таймером (вдох/выдох), случайной мотивирующей цитатой и экраном
   «Желание прошло».
7. **Инструкция по расширению.** 4 шага установки StayFocus Control
   (`chrome://extensions` → режим разработчика → «Загрузить распакованное» →
   вход) на лендинге и в кабинете.
8. **Бюджет ленты.** Дневной лимит для Instagram / TikTok / YouTube (5–120 мин),
   расход, заработанные минуты, сброс дня. Когда остаток равен нулю, канал
   блокируется: единственная кнопка — «Заработать время тренировкой». Состояние
   в `localStorage`, сбрасывается со сменой календарного дня.
9. **Тренажёр с камерой.** Экран блокировки предлагает отжимания (10 повторов,
   +10 мин) или приседания (20 повторов, +15 мин). MediaPipe PoseLandmarker
   (`@mediapipe/tasks-vision`) считает углы в локте / колене прямо в браузере:
   повтор засчитывается только при полной амплитуде, а для отжиманий ещё и при
   прямой линии корпуса — провисание и «домик» отбраковываются. Модель и WASM
   лежат в `public/mediapipe` (не CDN), видео не покидает устройство.

## Дизайн-система

Определена в [app/globals.css](app/globals.css) через Tailwind v4 `@theme inline`.

- **Тёмная тема (по умолчанию):** глубокий индиго/навигация `#05091a` →
  `#0a1130`, панели `#0c1430`, неоново-голубой `#22d3ee` и изумрудный `#34d399`.
- **Светлая тема:** свежий светло-голубой градиент `#eef5ff` → `#dfeaff` с той
  же акцентной парой.
- Токены фона, поверхностей, линий и текста переключаются классом `.dark` на
  `<html>`; выбор сохраняется в `localStorage`, а класс выставляется inline-скриптом
  до первой отрисовки (без вспышки).
- Движение: `float`, `glow`, `shine` (полоса прогресса), `pop` (галочка),
  `breathe` (дыхание), `burst` (победа) — все отключаются при
  `prefers-reduced-motion`.
- Бренд-марка: утверждённое лого — иконка-скруглённый квадрат с glowing-тропой
  на гору и гексагоном-вершиной, в палитре приложения.
  Ассет — `public/brand/stayfocus-icon.webp` (320 px, 13 КБ, прозрачные
  скруглённые углы), раздаётся через `next/image` уже ~48–72 px, поэтому
  остаётся резким на любом экране. Тот же рисунок используется как favicon
  ([app/icon.png](app/icon.png), 256 px). Исходный рендер сжали и замаскировали
  скриптом на `sharp`; в репозитории лежат только готовые ассеты.

## Языки

EN / RU / KZ переключаются капсулой в шапке и сохраняются в `localStorage`
(ключ `stayfocus.lang`). Словари в [lib/i18n.ts](lib/i18n.ts); английский объект —
источник истины для набора ключей, `TranslationKey` выводится из него, поэтому
недостающий перевод — ошибка типов. Там же `pluralDay()` с правилом 1 / 2–4 / 5+
и исключением 11–14 для русского.

## Чего пока нет и что нельзя сделать в браузере

- **Серверной части.** Профиль и лимиты живут в `localStorage`, ID-токен Google
  не проверяется на подпись. Для продакшена нужен бэкенд и верификация токена.
- **Реальной блокировки сайтов.** Веб-страница не может ни прочитать, ни
  остановить экранное время другого origin. Блокировка держится внутри
  приложения; чтобы ограничение действовало на самих сайтах, нужен
  Chrome-расширение (его бандла в репозитории нет) — шаги установки описаны.
- **Входа в TikTok / Instagram / YouTube с чтением времени просмотра.** Ни один
  публичный API этих платформ не отдаёт экранное время пользователя: TikTok
  Display API и Instagram Graph API работают с контентом и метриками аккаунта,
  YouTube Data API — с видео, а не с историей просмотров. Поэтому «привязка»
  аккаунтов и расход времени в прототипе демонстрационные.
- **Абсолютной невозможности обойти тренажёр.** Пока камера считает повторы,
  закрыть вкладку или выключить расширение технически можно — это ограничение
  любого веб-приложения, а не только этого прототипа.
